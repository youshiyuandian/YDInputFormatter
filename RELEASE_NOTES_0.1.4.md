# YDInputFormatter 0.1.4

This release cleans up documentation packaging by removing the Chinese README
and keeping a single English documentation entry point.

## Highlights

- Removed `README.zh-CN.md`
- Kept English `README.md` as the only top-level documentation entry
- Existing formatting APIs and integration modes remain unchanged

## Included in This Release

- `YDInputFormatter`
- `YDInputFormatterConfig`
- `YDInputFormatterResult`
- `UITextField+YDInputFormatter`
- `PrivacyInfo.xcprivacy`

## Installation

```ruby
source 'https://cdn.cocoapods.org/'

pod 'YDInputFormatter', '0.1.4'
```

If the CocoaPods CDN has not propagated to your environment yet, you can
temporarily install from GitHub:

```ruby
pod 'YDInputFormatter', :git => 'https://github.com/youshiyuandian/YDInputFormatter.git', :tag => '0.1.4'
```
